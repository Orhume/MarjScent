# Marj Scents — Storefront Test Version

A frontend storefront concept created for Marj Scents. This repository contains a test/live version and is separate from the actual production store.

## What it demonstrates

- Fragrance storefront layout and brand presentation
- Product collection browsing
- Product information and catalogue presentation
- Shopping-bag/cart interface and related frontend interactions

## Project status

This is a test version used during the storefront work. It should not be mistaken for the actual production website or the definitive live store.

## Technology

- HTML
- CSS
- JavaScript

## Run locally

Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Context

This repository is retained as a development/test artefact. The production store is separate.
